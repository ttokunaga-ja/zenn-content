dotのクラウド環境で、どのくらい開発作業ができるのかを確認しました。小規模なビルド・テスト、ローカルHTTP、SQLite・PostgreSQL・Redisは動作しました。Dockerの実行や常駐には制約があります。

:::message
2026年9月30日に利用できた環境での実測です。環境や実行条件によって結果は変わります。
:::

## 性能の目安

| 項目 | 実測・表示値 | 目安 |
| --- | --- | --- |
| CPU 1スレッド | sysbench 約2,169 events/s | Ryzen 9 3900XTの公開値の約95% |
| CPU 8スレッド | sysbench 約11,164 events/s | Core i7-7700の公開値の約1.25倍 |
| C++ 全体ビルド | 1並列 6.14秒 ／ 4並列 1.98秒 | 小規模な33ソースで約3.1倍に高速化 |
| C++ 差分ビルド | 0.26秒 | 1ソースを再コンパイル・リンク |
| 7-Zip 圧縮・展開 | 1スレッド 3,763 ／ 4スレッド 17,872 MIPS | 7-Zip独自の総合評価値 |
| SHA-256 | 約1.24 GB/s | 1ワーカーの暗号処理 |
| ストレージ 連続読込 | 約6,153〜6,279 MB/s | fio、短時間の転送 |
| ストレージ 連続書込 | 約3,186 MB/s | fio、短時間の転送 |
| ストレージ ランダム読込 | 約282〜344 MB/s | fio、4 KiB・QD32 |
| ストレージ ランダム書込 | 約329〜338 MB/s | fio、4 KiB・QD32 |
| CPU数 | 9論理CPU | 環境から見える数 |
| メモリ | 約9.7 GiB | 環境から見える総量 |
| 保存領域 | 約31.45 GiB、初期空き約29.23 GiB | 環境から見える容量 |
| GPU | この環境では利用できず | Vulkan・OpenCLで確認 |
| Cinebench・CrystalDiskMark | ネイティブ実行対象外 | 公式Linux版なし |
| Geekbench | 実行条件待ち | 非公開・オフライン実行にはPro版が必要 |

CPUの機種比較は、同じ素数計算での参考値です。CPU全体の性能を比較したものではありません。ストレージは短時間の結果で、CPU数・メモリ・保存容量は専有枠や保証値ではありません。

## GUIブラウザーで確認した画面

dot側の専用GUIブラウザーで公開ページのリンクを操作し、移動先のIANA「Example Domains」を表示したときの画面です。

![dot側のGUIブラウザーで表示したIANAのExample Domainsページ](/images/dot-cloud-developer-audit/gui-browser.jpg)
*公開ページでのリンク操作後に取得したスクリーンショット。ローカルで開発したWebアプリのE2Eテスト結果ではありません。*

## Android Studioの起動確認

![クラウド環境で起動したAndroid Studioの開始画面](/images/dot-cloud-developer-audit/android-studio-gui.png)

Android StudioのGUI起動と、別途コマンドラインでの未署名APK生成に成功しました。IDE内でのビルドやエミュレーター実行まで確認した結果ではありません。

## まとめ

**ビルド・単体テスト・DB検証はできますが、Webアプリの画面検証まで完結する開発環境としては確認できていません。** dot側のGUIからlocalhostに接続できず、シェルからのブラウザー起動にも問題があるためです。Docker必須の構成や常設サーバー用途にも制約があります。
